# 《HONG KONG》制作总结

给 The Weeknd 的新歌《HONG KONG (feat. 王菲季候風)》做的粉丝 MV。她在九龙一个路口上了的士，之后每天晚上，两只猫都去路口的绿色铁箱上守着。主角是苏州墙边茶馆的两只猫，豆包和茶茶。

制作时间 2026 年 11 月 6 日到 7 日。Claude 当导演，负责故事、分镜、出图、提示词、生成、剪辑和后期；Nicky 确认故事、画风、花费和粗剪，看片后提修改意见。成片前后出了 15 版，第 15 版定稿。

## 故事

她上车走的那个路口，两只猫每晚都去守着。城市一段段换了样子，她拖着歪轮子的行李箱回来，在路中间蹲下，猫听着轮子的节奏冲过去。

全片的四条规矩：

1. 街面镜头放在猫的高度，大人只露腿、手和后背。她的脸第一次出现在 171 秒，也是全片唯一露脸的人。
2. 红外套和黄花衬衫是她亲手做的，外套和她的风衣钉着同一种纽扣，衬衫和她的丝巾是同一块布。
3. 繁华段里猫走到哪穿到哪。每晚它们回到路口的铁箱上，同一个机位，身上换了一身，时间靠这个往前走。
4. 后半段只回到四个地方：窗台、电车、弥敦道、天台。

两只猫全片不变老。142 秒，绿铁箱换成一只高一截的灰色斜顶箱，豆包跳上去滑了下来，从此两只猫坐在地上，只看得到人腿，认出她靠的是歪轮子的声音。故事写到第四版，前两版各做过一次盲读。全文见 `story.md`。

## 流程

- Nicky 确认故事之后才出图，确认画风之后才出正式镜头。画风定稿前出了四张样帧。
- 每条 Seedance 提示词提交前，都由新开的审核 agent 对照首尾帧读一遍，写了"通过"才提交，然后报价、等 Nicky 同意。之后 Nicky 把剩下的工作交给 Claude 做完，此后 Claude 在积分上限内执行，每条任务记账。
- 最难的镜头先出：飞机过天台、63.5 秒的人潮、弥敦道两只猫、跳新箱打滑、黑伞海、猫穿过人腿、头顶进手心、招牌亮起。
- 每条片段下载后查硬切，再放大到原始分辨率数爪、耳、尾和手指。两轮分别查了 48 镜和 22 镜，没有多出的猫爪或猫耳，人手有一处错。
- 切点全部对在 69 BPM 的拍子网格上，片段长度按帧算。
- 每一版成片都由新开的审片 agent 看占位符版（歌词的英文字母画成 H，中文画成"永"），报告硬伤和小问题。每一轮修复后再审一次。

## 后期

- **调色**：低调，青绿和血红，红色光晕，胶片颗粒，轻微暗角，一层很小的手持晃动。参数在 `finish_spec.json`。
- **压 AI 感**（第八版起）：全片颗粒加两成，叠一成柔光，四角再软一点，每帧亮度有 0.4% 的随机起伏。她的特写柔光加到三成。
- **抽帧**：12 fps。主体几乎不动的镜头相邻两帧叠化，动得快的镜头一帧停两帧不叠化。Nicky 觉得抽帧有味道，第八版在 82 到 167 秒之间又加了几镜。
- **歌词**：英文用 Futura 大写加字距，放在每个镜头的留白处，霓虹一样逐词亮起，地面有倒影，切镜时熄灭。中文用魏碑竖排，每个分句一列，像老香港的招牌。歌词文字来自 Nicky 提供的文件，工具运行时读取，只输出时间和位置。制作过程中 Claude 没有打开、校对或转写过这份文字，审核也都看占位符版。
- **歌词时间**：Nicky 看第六版时指出字和唱不够准。查下来是 Whisper 对齐的问题：一句的第一个词会吞掉前面的空拍，英文句首词平均早亮 0.93 秒，最多早 3.1 秒，句中词平均早 0.2 秒。英文改用截断测试重新定位（`scripts/lyric_cut_test.py` 是它的通用版）。Whisper 听不出副歌的中文，中文用两遍副歌共有的起音（两遍相隔 97.391 秒，音频互相关 0.644）加小节结构来定。
- **署名**：歌曲的曲名、演唱、发行日期、词曲和制作，采样的《季候風》的演唱、作曲、作词、编曲、专辑和厂牌，都对照了 Apple Music、Spotify、KKBOX、Album of the Year 和几家音乐媒体。《HONG KONG》的厂牌没有找到明确记载，没写。

## 查片和修复

| 问题 | 处理 |
| --- | --- |
| 她摸豆包头的手不自然（Nicky 指出） | 首尾帧的手重画，提示词重写，审核通过后重拍三条，用手一直贴在猫头上的那条 |
| 她第一次露脸比后面老十岁，盲审读成另一个人 | 改用 R8 的首帧重拍，只取抬头之后的帧，水平翻转，裁掉膝盖 |
| 她埋头时湿发垂到前臂，读成长发，放大像恐怖片 | 她在这一镜不动：42 帧取中值底板，用 GPT Image 把头重画成贴头皮的湿短发，合回时只叠长条雨线（`scripts/plate_repair.py`） |
| 同一镜她的手比脸老，手背有疤一样的亮痕 | 同一张底板上重画两只手，姿势不变，合回时只叠三个通道都亮的雨线 |
| 猫在空中飘 | 跑动段提速 2.1 倍，刹住段回到原速 |
| 一团粉云三秒滑过半个天空，读成贴上去的 | 固定机位，天空那块放到四分之一速度，猫保持原速 |
| 灰猫的爪伸到奶油猫下巴下，读成第五只爪 | 这 14 帧用爪子进来之前的地面盖掉 |
| 灰猫看着有三只前爪 | 靠后的白爪压暗成阴影 |
| 灰猫回头时耳朵成空心线框 | 整镜拉慢，在回头之前收 |
| 第二段街上走，开头进得慢（Nicky 指出） | 源片前 24 帧几乎不动：从第 14 帧起，开头快放，中段原速，收尾半速，速度用光流中间帧渐变（`scripts/flow_ramp.py`） |
| 同一镜猫脸有重影 | 抽帧用了两帧叠化，猫走近时读成双眼，改成一帧停两帧 |
| 某镜每 4 帧重复 1 帧（Seedance 片子自带） | 试过用光流中间帧替换，复核查出半透明的单帧，撤回，保持原片 |
| 六处句尾词没亮完就被切掉 | 硬切块的末词至少亮 15 帧，前面的词跟着提前 |
| 49 秒和 1:30 一句的最后一个词或字单独落到下一镜（Nicky 指出） | 整句做成一块，放在前后两镜都空着的地方，跨切点不动，最后一个词在原地按唱的时间亮起 |
| 中文落在白袖口上读不清 | 淡的暗光晕只把对比从 1.9 提到 2.1，改成每个字下面一圈实的深色描边 |
| 窗外暗到几乎全黑，猫和屋里也一起暗 | 增益按猫算，猫的亮度持平；窗外按街面实际跌了多少补多少亮底板，跌幅从八成收到一成以内 |
| 车顶灯管在固定机位里沿天花板滑下来 | 车顶换成灯管静止那段的底板，猫按皮毛颜色抠出，底板按车身实测的抖动逐帧移动 |
| 手指急落，扣子跳位、变形、半透明 | 只改手这一块的时间，坏的 20 帧不用，用光流过渡 |
| 超分把橘猫头上的湿毛放大成龟裂纹 | 猫头这块用 85% 的 1080p 画面换回 |
| 片尾卡读不完（两轮） | 拆成四张，每张 3 到 6 行，按每秒 4 个词定全亮时间（`scripts/card_timing.py`） |

盲审提出、Claude 看过之后决定不动的：远景里站起来的橘猫身形偏长（分镜就是站起来又坐回去）；水滴打到猫头时耳朵压平（读成猫的反应）；绿铁箱换成灰色斜顶箱，两轮盲审都当成问题（这是故事设计，观众未必看得懂）。

Nicky 确认不用改的小问题：两辆的士的车门铰链方向不同；窗灯镜头里猫外面有 7 帧亮边；六处下一列的第一个字在切镜前单独亮 16 到 20 帧；一镜结尾两只手同向平行；片尾第三张卡全亮 6 秒，按每秒 4 个词算需要约 7.75 秒。

## 交付时说明的事

- 歌词的错字和断句要 Nicky 自己看一遍，中文副歌的时间准不准要 Nicky 听一遍。
- 她全片没有笑。原分镜里抬头含泪笑的那一镜，脸比前后显老，改成了全程低头闭眼抱猫。要不要补一版笑的镜头，由 Nicky 决定。
- 机翼频闪的一段亮度变化快，平台要做光敏测试的话要留意。
- Claude 听不到声音，也看不到真实的动态。节奏只按测量的切点和帧序列检查过。全片 −15.9 LUFS，真峰值 −0.8 dBFS，这些是测量值。

## 2026-11-09 补记：音画对位的测量有偏差

当时测出全曲重音比切点网格早约 50 毫秒，就把音轨整体延后了 48 毫秒。做这个 skill 时给测量脚本加了测试，用已知时间的合成节拍声去测，发现它把每个起音都标早了约 36 毫秒：分析窗口按起点标时间，而一个敲击要等它进入窗口的后段才最明显。校准后重测，重音只比网格早约 13 毫秒。所以成片的音轨现在比切点晚约 35 毫秒。这不到一帧（41.7 毫秒），而且声音稍晚是观众最不容易察觉的方向，成片不改。`scripts/beat_grid.py` 已经带上校准，以后的片子按校准后的数字处理。
